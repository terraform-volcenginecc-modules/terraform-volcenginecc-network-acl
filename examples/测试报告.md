## 已发现并修复的问题

1. 可选 `rule.name` 未设置时，变量校验会执行 `trimspace(null)`；已改为显式条件表达式。
2. 空 `subnet_ids` 传递为 `resources = []` 会被 Provider 回读为 Optional+Computed 差异；已改为空关联传递 `null`。
3. 输出遍历空关联时会对 `null` 迭代；已使用 `coalesce(..., [])` 处理。

## 执行约束

Cloud Control 不接受同一 VPC 的多条 ACL 并发创建。`complete` 部署必须使用：

```bash
terraform apply -parallelism=1
terraform destroy -parallelism=1
```

InfraManager 任务也必须将 Terraform 并行度设为 `1`，否则同一 VPC 的多个 ACL 可能出现 `InvalidOperation.Conflict`。

## 未覆盖项

- 按用户要求跳过规则优先级及默认规则检查。Provider `0.0.70` 将它们暴露为只读字段。
